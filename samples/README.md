# Sample files

*[Deutsche Fassung weiter unten](#beispieldateien)*

Markdown files to try mdVü out with. Download the folder (or the single file you're curious about), drop it onto the mdVü window and browse.

| File | What it shows |
|---|---|
| [`showcase.md`](showcase.md) | every element mdVü renders — headings, lists, tables, callouts, images, task lists — plus an honest section on what stays plain text |
| [`code-samples.md`](code-samples.md) | syntax highlighting across a dozen languages, from Pascal to Python |
| [`example-user.css`](example-user.css) | a commented starting point for your own stylesheet: copy it into *View → CSS* (`Ctrl+4`) |

German versions are next to them: `showcase.de.md`, `code-samples.de.md`.

These files are MIT licensed — copy them into your own projects, use them as test fixtures, take the CSS apart. See the [LICENSE](../LICENSE.md) for the details.

# Beispieldateien

Markdown-Dateien zum Ausprobieren. Ordner (oder einzelne Datei) herunterladen, auf das mdVü-Fenster ziehen, stöbern.

| Datei | Was sie zeigt |
|---|---|
| [`showcase.de.md`](showcase.de.md) | jedes Element, das mdVü darstellt — Überschriften, Listen, Tabellen, Callouts, Bilder, Aufgabenlisten — dazu ein ehrlicher Abschnitt über das, was einfacher Text bleibt |
| [`code-samples.de.md`](code-samples.de.md) | Syntaxhervorhebung quer durch ein Dutzend Sprachen, von Pascal bis Python |
| [`example-user.css`](example-user.css) | ein kommentierter Ausgangspunkt für das eigene Stylesheet: Inhalt nach *Ansicht → CSS* (`Strg+4`) kopieren |

Die Dateien stehen unter der MIT-Lizenz — sie dürfen in eigene Projekte übernommen, als Testdaten verwendet und beliebig zerlegt werden. Einzelheiten in der [LICENSE](../LICENSE.md).
